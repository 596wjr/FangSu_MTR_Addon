# NTE 轨道模型组合

NTE 画刷的轨道模型选择页由方速接管：主轨道单选，Fsrail 的第三轨、桥梁边缘、中部和护栏（含镜像）独立多选。点击“关闭并保存”或按 Esc 保存，再回到原来的画刷配置。其他自定义模型仍作为主轨道候选。

## 实现

- `NteRailSelectionScreenMixin` 用 `@Pseudo` 和字符串 `targets` 接入 NTE 0.5.x 的 `BrushEditRailScreen.loadPage`，以及 ANTE 1.1.0 的 `BrushEditRailScreen$SelectScreen.loadPage`。兼容无前缀、`fabric.`、`forge.` 三种类名，未安装时不加载目标。
- 单模型仍保存原 ID。组合保存为 `fangsu:rail_layers:["main_tp1","ex_dsg","ex_bredge"]`，沿用 NTE 的 `ModelKey` / `model_key` 字符串字段及原有画刷、网络和世界保存流程。无需增加包字段。客户端需要安装方速才能正确显示组合；原生 NTE 客户端会回退到默认轨道。
- `NteRailLayersMixin` 让主模型走原流程，附属各自生成 `BakedRail` 并加入 NTE 的模型分块；重复间隔、偏移、实例化/网格渲染均由 NTE 处理。不会把不同间隔的模型合并成一张原始网格。
- 修改组合时让原分块缓存失效；移除轨道、切换渲染模式或资源重载时移除附属引用，由 NTE 原有流程关闭分块缓冲。几何参数查询只取主轨道。
- MTR4 同步保存可选补丁；其原生轨道工具继续使用原有多选功能。

## 手动验证

1. 未安装 NTE：启动、载入世界，检查可选 Mixin 不影响原功能。
2. 安装 NTE，使用其画刷编辑轨道，开启模型覆盖；选择标准轨道类型 1，同时选择第三轨和桥梁边缘。确认三个模型都显示。
3. 保持主轨道不变，只增删附属，确认立即刷新；更换主轨道，确认附属仍保留。
4. 用画刷批量应用到其他轨道，检查双向轨道与反向附属位置；退出重进世界，确认组合保留。联机检查其他装有方速的客户端看到相同组合。
5. 切换 NTE 网格/实例化轨道渲染模式，重载资源、卸载区块、删除轨道，确认无残留模型或报错。NTE 必须启用自身的 3D 轨道渲染才能显示附属。
6. 打开旧存档的单模型轨道（包括旧的单附属选择），确认保持显示；再保存普通单模型，确认恢复为原 ID。
7. 对 ANTE 1.1.0 重复画刷选择与保存检查。MTR4 未安装 NTE 时，检查原生轨道工具多选不受影响。

本次仅核对本地 NTE 0.5.2 / ANTE 1.1.0 缓存 jar 的目标方法、字段和构造器，以及源码和资源的一致性；未执行编译或进游戏验证。
